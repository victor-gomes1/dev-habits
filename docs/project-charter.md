# Termo de Abertura do Projeto (Project Charter) - DevHabits

## 1. Visão Geral do Projeto
O **DevHabits** é uma aplicação voltada para o gerenciamento de rotinas de estudo, desenvolvimento de software e hábitos de produtividade para programadores. O objetivo é fornecer ferramentas estruturadas de acompanhamento diário para maximizar a constância técnica.

## 2. Justificativa e Objetivos
- **Problema:** Desenvolvedores e estudantes de tecnologia frequentemente perdem o foco ou a consistência devido à falta de rastreabilidade e métricas claras sobre sua rotina diária de código.
- **Objetivo Principal:** Criar um ambiente digital integrado para cadastro de hábitos, controle de check-ins e visualização de progresso histórico de forma simples e eficiente.

## 3. Escopo do Produto
- Cadastro e autenticação de usuários.
- Criação e gerenciamento de hábitos personalizados.
- Registo de conclusão diária de tarefas (*check-ins*).
- API RESTful estruturada em TypeScript, Node.js e PostgreSQL.
